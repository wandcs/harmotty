## 完成定义

只有在以下条件同时满足后，P0 才完成：

- AGC 证据仍可独立恢复和核验；
- 公开仓库不包含秘密、个人环境、内部历史或不支持的平台产物；
- 公开 CI 运行真实检查，不使用假成功；
- 外部参与者能够安全提交 Issue 和 PR；
- 官方包、源码、Fork 和第三方构建的边界清楚；
- 匿名干净 clone 的公共检查通过。

完成 P0 后，新的产品工作必须依据
[`project-principles.md`](project-principles.md) 重新进入本文件；历史材料不自动
