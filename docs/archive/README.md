# Documentation archive

This directory is reserved for public documents that have been completed,
superseded or retained only for historical context.

The private development archive that predates the first public source baseline
is intentionally excluded because it contains internal investigation details,
machine-specific data and obsolete implementation plans. Its absence does not
remove any active project requirement: `docs/next-work.md` is the only current
TODO and `docs/project-principles.md` is the governing rule.

Checkboxes and proposals in future archived documents are historical and do not
authorize implementation unless they are explicitly promoted back into
`docs/next-work.md`.
