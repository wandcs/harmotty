# Documentation archive

This directory is intentionally limited to this policy notice.

Completed and superseded public plans are removed from the current tree rather
than kept as a second documentation set. They remain recoverable from Git
history when historical inspection is necessary.

Private release evidence, machine-specific records and the development archive
that predates the first public source baseline remain outside this repository.
Their absence does not remove any active project requirement:
`docs/next-work.md` is the only current TODO and
`docs/project-principles.md` is the governing rule.

If an exceptional public historical document is retained here in the future,
it is evidence only. It does not authorize implementation unless work is
explicitly promoted back into `docs/next-work.md`.
