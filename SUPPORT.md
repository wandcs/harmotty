# Support

LeanTTY is a small open-source project and does not provide a service-level
agreement or private end-user support.

Use GitHub Issues for:

- reproducible LeanTTY defects on an ARM64 HarmonyOS PC;
- inaccurate or incomplete project documentation; and
- bounded feature proposals that address the core remote-terminal path.

Before opening an issue, search existing issues and test the latest supported
version when practical. Include the LeanTTY version or commit, HarmonyOS
version, connection method and minimal reproduction steps.

Redact usernames, hostnames, IP addresses, device identifiers, terminal history,
private keys, passwords, tokens and production logs.

General SSH server administration, HarmonyOS account problems, DevEco
installation, unsupported devices and custom forks are outside the support
boundary. Community members may still help, but maintainers may close such
requests.

Suspected vulnerabilities must be reported privately through
[SECURITY.md](SECURITY.md).
